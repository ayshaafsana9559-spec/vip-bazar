# projects

Working area for Figma → HTML conversions.

For each screenshot the user provides, create a folder named after the section or page, for example `projects/home-banner/`. Keep in it:

- `notes.md`: the measurements taken from the screenshot (artboard width, paddings, gaps, font sizes, colors, and which token or utility each maps to), any assumptions, and the files changed in `src/`.
- Reference screenshots or exported assets, when provided.

The production code itself lives in `src/` (see the `figma-to-html` skill).
